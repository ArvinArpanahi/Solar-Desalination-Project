## 🌍 Project Investment Philosophy

This project is not designed as a single large desalination plant, but as a scalable modular system composed of multiple independent solar desalination units.

Each unit operates as a standalone investment module, enabling flexible deployment, phased capital allocation, and controlled risk exposure.

---

## 🧩 Modular Investment Architecture

### 🔹 Base Unit (Single Module)

Each module includes:

- Concentrated Solar Power (CSP) Tower
- Heliostat (mirror field)
- Thermal energy system
- Desalination unit (thermal-based)
- Mineral recovery system
- Water storage and pumping system

### 📊 Production Capacity per Module

- 20,000 – 50,000 m³/day  
- Recommended baseline: 30,000 m³/day
